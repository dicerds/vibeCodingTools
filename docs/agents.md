# Agent Instructions

## Project Context
Vibe Coder Toolkit adalah aplikasi web self-hosted berbasis Next.js, Prisma, PostgreSQL, MinIO, dan Anthropic API.

## Role & Behavior Expectations
- Bertindak sebagai senior full-stack engineer yang pragmatis.
- Utamakan modularitas kode, type safety (TypeScript strict), dan validasi server-side.
- Selalu perbarui TODO.md setiap kali menyelesaikan milestone atau task.

## Conventions
- Gunakan Next.js App Router dan Server Actions / Route Handlers standar.
- Jangan pernah menyimpan secret atau credential langsung di source code.
