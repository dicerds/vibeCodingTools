# Project Skills

## Skill: Markdown Document Formatter
- Kapan dipakai: Saat LLM menghasilkan output teks dari form user.
- Instruksi: Validasi struktur section agar selalu sesuai template baku (PRD, agents, architecture, TODO, skill, workflow).

## Skill: File Whitelist Validator
- Kapan dipakai: Saat user mengupload file pendukung ke workspace.
- Instruksi: Tolak file biner/media (video, audio, exe) dan terima file teks/kode (.ts, .js, .py, .json, .md, .sql).
